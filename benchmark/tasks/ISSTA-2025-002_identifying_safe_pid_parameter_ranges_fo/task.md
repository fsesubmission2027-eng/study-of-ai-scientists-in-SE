# Task: ISSTA-2025-002 — Identifying Safe PID Parameter Ranges for Drones to Prevent Misconfiguration-Induced Crashes

## Background

Unmanned aerial vehicles (UAVs) rely heavily on flight control software containing PID controllers with user‑configurable proportional, integral, and derivative parameters. These parameters can be adjusted in‑flight for different tasks, but flight control programs lack adequate input validation, enabling misconfigured PID values to push a UAV into dangerous states such as path deviations, loss of control, or crashes. Existing approaches (e.g., fuzzing) treat each PID parameter independently, missing critical interdependencies in the three‑dimensional parameter space, and therefore fail to reliably identify multi‑dimensional ranges of safe configurations. Moreover, each flight simulation used to test a single parameter set is extremely time‑consuming, making exhaustive or purely random exploration impractical. An effective technique is needed to efficiently determine valid multidimensional PID parameter regions so that input validation bugs can be detected during real‑time flight operations.

## Research Question

How can we efficiently and accurately identify valid three‑dimensional PID parameter ranges for UAV flight controllers, given the high cost of simulation and the interdependencies among parameters?

## Experiment Setup

### Datasets
```
- name: PID parameter validity benchmark
  source: Constructable using open‑source flight control software (ArduPilot and PX4) with their associated simulators (SITL and jMAVSim) by exhaustively testing PID parameter configurations in each flight mode and classifying them with a misbehavior oracle.
  description: A ground‑truth labelled set of PID parameter configurations (valid/invalid) generated by systematic simulation testing over eight flight modes; construction required approximately 7,000 CPU hours.
  access: constructable
```

### Baselines
```
- name: PGFuzz
  reference: A prior random‑fuzzing tool for detecting PID parameter misconfigurations in UAV flight controllers.
```

### Metrics
```
- name: Accuracy
  definition: The proportion of PID parameter configurations correctly classified as valid or invalid when compared to the ground‑truth benchmark.
- name: Number of misconfigurations discovered
  definition: Total count of distinct invalid PID parameter configurations identified within a given time budget (e.g., 48 hours).
```

### Sub-questions
```
- RQ1: How accurate is the identified valid/invalid PID parameter region compared to a ground‑truth benchmark?
- RQ2: How many individual PID parameter misconfigurations can be detected within a fixed 48‑hour time budget?
- RQ3: How does the choice of search algorithm (e.g., hill climbing, genetic algorithms) affect the accuracy and efficiency of boundary identification?
```

### Target Subject

Open‑source UAV flight control software (ArduPilot and PX4) with PID control modules, evaluated across diverse flight modes such as auto‑return, circling, and zigzag patterns.

### Constraints

Experiments must be conducted within the ArduPilot SITL and PX4 jMAVSim simulation environments using the same flight modes and PID parameter bounds as in the original study. Each single‑simulation test takes hundreds of seconds. Ground‑truth construction demands roughly 7,000 CPU hours, and the 48‑hour search experiments require high‑core‑count machines. The parameter search space is bounded by documentation‑provided ranges for each flight mode.

## Feasibility Notes

The required UAV simulators and flight control programs are open‑source and publicly available, so the environment can be reproduced with effort. The ground‑truth benchmark is not pre‑packaged but can be generated using the same simulation procedure, though it is extremely computationally expensive (~7,000 CPU hours). The search experiments also demand significant resources (runs of 48 hours). Building an accurate misbehavior oracle (e.g., via temporal logic specifications) requires domain‑specific knowledge of UAV flight safety properties.
